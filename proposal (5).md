## In just a sentence or two, summarize your project. (E.g., "A website that lets you buy and sell stocks.")

## In a paragraph or more, detail your project. What will your software do? What features will it have? How will it be executed?

My project is a maze game in Python. The player controls a Pac-Man-style character with the up, down, left, and right arrow keys. The goal is to get through the maze without going through any walls, find a key and pick it up, and then get to the exit. The player collects the key, and then the exit opens. I am going to use Python Turtle to draw and control the character and also to create the game window and draw the maze. The game is played by opening the Python file and starting it. I would also want to display a winning message when the player successfully escapes.
